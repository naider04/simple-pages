# Simulador B1 — CERTIFIED EXAM PREPARATION B1

Practica con el banco de preguntas únicas del curso **CERTIFIED EXAM PREPARATION B1**
(aulagradoa.unemi.edu.ec): **137 preguntas** de 8 quizzes (Grammar, Listening,
Reading, Writing y sus simuladores).

- Selecciona tu respuesta (opción múltiple / una por subpregunta) y pulsa **Comprobar**.
- Al comprobar se revela la respuesta correcta y el feedback.
- La puntuación se acumula y al final aparece el resumen con **Reiniciar**.
- Audios de listening incluidos en `resources/` (funciona sin conexión).

## Uso local

```sh
php -S localhost:8000      # o: python3 -m http.server 8000
# abrir http://localhost:8000
```

Abrir `index.html` directamente también funciona (los audios son rutas relativas).
